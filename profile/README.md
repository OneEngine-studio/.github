##  About oneEngine

**oneEngine** is an independent game engineering studio and research team dedicated to pushing the boundaries of real-time interactive entertainment. We merge cutting-edge rendering pipelines, deep reinforcement learning agents, and distributed cloud game-server architectures to build living, reactive virtual worlds.

---

##  Flagship Project: *Railbound*

> **A high-stakes tactical third-person shooter set in a volatile, moving train network battleground.**

* **High-Fidelity Rendering (HDRP):** Calibrated physical Lux daylight, volumetric atmospheric scattering, screen-space reflections, and custom world-scan sonar FX.
* **Evolving Autonomous RL Combatants:** Enemy squads driven by ML-Agents reinforcement learning policies that dynamically adapt their tactical flanking, cover suppression, and aggression in real time.
* **High-Performance Dedicated Netcode:** Low-latency UDP networking powered by Unity Netcode for GameObjects, client-side predictive transforms, and lag compensation.
* **Hybrid Cloud-Edge GitOps:** Micro-cluster infrastructure containerized with Docker, automated continuous delivery via ArgoCD, and secure multi-cloud WireGuard tunnels.
